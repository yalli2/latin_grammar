# Lingua Latina — Interactive Latin Grammar

KCIS 라틴어 수업용 인터랙티브 학습 사이트 · Interactive Latin course site for the KCIS Latin class.

- 31 units following the course book *Complete Latin* (Gavin Betts, Teach Yourself)
- Grammar summaries with full paradigm tables (click a form to hear it)
- Vocabulary list + flashcards
- Every *Latin reading* / *Extra reading* exercise: multiple-choice or free-writing mode, instant scoring
- Grammar quiz for every unit, results page with per-section scores (saved in the browser)
- Latin audio: Classical (restored) or Ecclesiastical pronunciation using the best Latin/Italian voice on the device
- Interface languages: 한국어, English, Español, 中文, 日本語, Français, Deutsch, Português, Italiano, Русский, Tiếng Việt, Bahasa Indonesia (lesson content in Korean and English)

Live site: https://yalli2.github.io/latin_grammar/

Structure: `index.html` (main page) · `unit.html?u=N` (unit page) · `data/unitNN.js` (lesson data) · `js/` · `css/`.
